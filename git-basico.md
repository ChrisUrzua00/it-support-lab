Conceptos básicos.
Git add: el comando establece cambios en el directorio de trabajo para el siguiente commit de nuestro proyecto; sirve para agregar archivos, lineas de texto dentro de archivos de texto compatibles, e incluso rutas de acceso a carpetas importantes para el desarrollo del proyecto. Esto es un preliminar, hasta no ejecutar el comando Git commit se guardan oficialmente los cambios.
Git commit: el comando git commit nos permite confirmar los cambios del comando anterior, estableciendo todo el proceso en etapas, mostrando versiones distintas antes del cambio y después. Básicamente el Git commit muestra por escrito la confirmación de los cambios hechos con el comando anterior. Se utiliza la introducción -m para desplegar el mensaje posteriormente con las especificaciones de los cambios realizados. Ej. git commit -m "El código que ejecuta X acción ha sido reemplazado por una versión optimizada", de modo que los colaboradores estén enterados de los cambios.
Git push: se utiliza para empujar cambios, comandos, ramas o cualquier tipo de información contenida del repositorio local a uno remoto. Existen reglas que establecen el tipo de contenido que se envía. En el siguiente link puedes encontrar información completa al respecto: https://github.com/git-guides/git-push ke pagina tan god ahi encontré todo y se entiende muy bien.
Conclusiones: los comandos pueden ser complicados de entender, hay que tener bien establecidas las funciones básicas antes de querer introducir códigos o modificar información con comandos dentro de un repositorio, pero son muy útiles una vez que los comprendes, sigue siendo un misterio porque no terminas de entender la estructura así que cuando avancemos todo irá cobrando más sentido.
